# G Server

Лендинг поставщика профессиональных GPU, AI-ускорителей, GPU-серверов и серверной памяти по России.

Живая версия: [nasledie-it-supply.metriccord512.chatgpt.site](https://nasledie-it-supply.metriccord512.chatgpt.site/)

## Возможности

- адаптивный светлый первый экран с видео G Server и автозапуском без звука;
- каталог NVIDIA и Samsung с отдельными страницами товаров;
- фигурная зелёная панель статистики и bento-категории со светлыми и тёмными карточками;
- получение запросов через корпоративную почту и телефоны без передачи персональных данных через сайт;
- SEO-метаданные, Open Graph и Schema.org;
- Cloudflare Worker без сторонних runtime-зависимостей.

## Локальный запуск

Нужен Node.js 20 или новее.

```bash
npm run build
npm run validate
npm test
npm run preview
```

После запуска сайт доступен по адресу `http://127.0.0.1:4190`.

## Структура

```text
worker/
  index.js          данные товаров, страницы товаров и политика обработки данных
  home-v2.js        главная страница и визуальный интерфейс
scripts/
  build.sh          сборка Worker
  embed-hero.mjs    подготовка встроенных изображений
  preview.mjs       локальный сервер
  validate-artifact.mjs
assets/             исходные изображения
.openai/hosting.json
```

## Получение запросов

На сайте нет формы заявки, аналитики и рекламных пикселей. Кнопки запроса открывают корпоративную почту `info@nasledie77.ru` с готовой темой и шаблоном письма; также доступны прямые телефонные ссылки. Сайт не принимает и не хранит контактные данные посетителя.

На `/privacy` опубликована политика обработки персональных данных с реквизитами ООО «НАСЛЕДИЕ».

## Основные команды

```bash
npm run build      # собрать dist/
npm run validate   # проверить deployment artifact
npm run preview    # открыть локальный сервер на порту 4190
```

## Медиа главной страницы

- `assets/hero-gpu.mp4` — предоставленный владельцем ролик, оптимизированный до 1600 × 890, 5 секунд, без аудио.
- `assets/hero-gpu-poster.webp` — первый кадр для быстрой загрузки и режима уменьшенной анимации.
- `assets/categories/` — иллюстрации категорий; фотографии конкретных товаров остаются в `assets/products/`.
- Видео автоматически проигрывается один раз без звука и останавливается на последнем кадре. При `prefers-reduced-motion: reduce` остаётся обложка.
- `npm test` собирает сайт и проверяет выдачу медиа, включая частичные запросы видео, режим уменьшенной анимации, страницы товаров, каналы связи и страницу политики.

Иллюстрации категорий созданы встроенным image_gen: чёрная профессиональная видеокарта и серебристо-чёрный стоечный сервер, фотореалистичный ракурс три четверти, прозрачный фон, без надписей и логотипов. Оптимизированы в WebP с сохранением прозрачности.
